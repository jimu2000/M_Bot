## 其他云功能（BOT-README + cloud.md）

  Lightsail 列表/创建/启停/删除、本月流量、静态IP创建绑定解绑释放与换静态IP、重启换IP、防火墙端口、IPv6开关；

- GCP：实例列表（全可用区）/创建（提示免费档）/启停重启/删除（Telegram通知）/换IP、
  概览（免费档e2-micro数量）、近3个月流量。
- Azure：虚拟机列表/创建删除重启/换IP/资源用量配额。
- DigitalOcean：Droplet列表/创建（可批量、开机脚本）/开关机重启、
  保留IP分配绑定解绑释放、流量、账单（余额/本月费用）。
- SolusVM：VPS列表/状态详情/开关机重启。
- VirtFusion：按厂商分组的实例列表（状态/IP/CPU/内存/硬盘/创建时间）、流量、SSH连接、
  开关机重启强制关机、改名、重置密码。
