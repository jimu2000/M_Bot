# R-Bot Web 版界面分析（阶段 3 参考）

截图来源：R-Bot 公开仓库 screenshots/ 目录，已保存到本目录 screenshots/。
文档：webssh.md（Web SSH 终端指南）、cloud.md（Web 云管理面板指南）。

## 整体布局（所有页面通用）

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：R-SSH logo | 语言（简体中文） | 主题（星夜⚡） | 设置 | 明暗切换 | 退出 │
├──────────────────────────────────────────────────────────────┤
│ 资源栏：导航图标（面板/密钥/云） | CPU% 内存% 硬盘% 网络↓↑ | R-SSH% | SFTP 全屏 ＋ │
├──────────┬───────────────────────────────────────────────────┤
│ 左侧边栏  │ 主内容区                                           │
│ （云管理）│                                                  │
└──────────┴───────────────────────────────────────────────────┘
```

- **顶栏**：logo + 语言切换 + 主题切换（8 种主题 × 明暗）+ 设置 + 退出。
- **资源栏**：实时 CPU / 内存 / 硬盘 / 网络上下行速率 + 客户端自身占用。
- **主题**：经典（默认蓝）、樱花（粉）、赛博（霓虹青蓝）、水墨（金色国风）、
  极光（青绿紫）、星夜（深紫星空，截图里是这个）、海渊（深海蓝绿）、日落（暖橘）。
  每种都有亮色和暗色。星夜主题带二次元插画背景（月亮上的女孩）。
- **⚡ 标记**：付费"闪电"功能，克隆时跳过（不做付费墙）。

## 主机面板（terminal-list.jpg）

- 标题："已保存会话 N" + 搜索框；右上角"同步云主机⚡"和"添加"按钮。
- 主机卡片（网格布局），每张卡片：
  - 名称 + 认证方式徽标（密码/密钥）
  - 平台信息：SVM·racknerd-xxx·IPv6 / OCI·VM.Standard.A1.Flex (STOPPED) / SVM·debian
  - 标签：操作系统（Debian GNU/Linux 12）、CPU 核数、内存、硬盘
  - IP（可一键复制）、用户名（root）
  - 上次使用时间（2天前 / 5天前，绿点表示在线状态）
  - 操作按钮：▶ 连接、复制、编辑、删除
- 卡片可按标签筛选、按名称/IP 搜索。

## SSH 终端（terminal.jpg）

- 标签页：每个连接一个标签（Amsterdam），绿点表示已连接，× 关闭。
- 右上角：SFTP、全屏、＋（新连接）按钮。
- 终端内右上角：实时 CPU / MEM / DISK / 网络速率。
- 连接后自动显示欢迎横幅：R-SSH ASCII 艺术字 + uname + uptime + df -h + free -h。
- 工具条（文档）：收藏⭐、搜索、常用工具、分屏、挂起。
- 多行粘贴保护：粘贴多行不直接执行，停在输入行按回车才跑。
- 会话挂起：类似 screen，关页面不断开，下次接回（最多 20 个）。
- 分屏：左右一分为二，一键克隆当前连接，刷新后布局保留。
- SFTP：终端下方滑出文件面板，浏览/上传/下载/在线编辑（语法高亮）/删除/新建目录，
  传输管理器看进度和速度；OpenWrt 等无 SFTP 的设备走兼容模式。
- 端口转发：本地转发 / 远程转发，在配置抽屉里设。
- 批量命令：勾选多台主机，一条命令群发，结果按主机分开展示，可接着执行。

## 云管理面板（cloud-dashboard.jpg、cloud-create.jpg）

- 云厂商标签：Oracle Cloud / Azure / SolusVM（顶部切换）。
- 左侧边栏：概览⚡、实例管理、启动盘、用户管理、创建实例、任务管理、
  DNS 管理、对象存储、邮件服务。
- Profile 下拉：切换 OCI 账号（如 toronto-22-10-29b、demo）。
- 右上角："返回主机列表"按钮。

### 创建实例表单（cloud-create.jpg）

四张卡片 + 快捷开机 + 提交按钮：

1. **基础配置**：Shape 下拉（VM.Standard.A1.Flex (1-80 OCPU, 1-512 GB)）、
   OCPU 输入（4）、内存 GB 输入（24）。
2. **系统配置**：镜像 / 启动盘⚡ 标签页、镜像下拉
   （Canonical-Ubuntu-24.04-aarch64-2026.02.28-0）、硬盘大小 GB（50）、数量（1）。
3. **网络与安全**：公网 IP 开关、IPv6⚡ 开关、传输加密开关、设置 Root 密码开关、
   SSH 公钥下拉（不使用公钥）+ 上传公钥按钮。
4. **高级选项**：最小延迟（20）、最大延迟（50）、启动脚本⚡ 文本框。
5. **快捷开机⚡**：已保存的配置卡片网格（2cArm、e3 test、arm bug、2cARM test、
   2个AMD50、E4 test、4CARM、AMD、amd 无ip、2个ARM），点一张填满表单。
6. **开始创建**按钮（蓝色，右下角）。

### 对象存储（cloud-dashboard.jpg）

- Bucket 下拉（test (公开) 811.0 KB）+ 刷新 / 新建文件夹⚡ / 上传文件⚡ / 创建 Bucket⚡。
- 文件表：名称 / 修改时间 / 大小 / 操作（下载、复制链接、删除）。
- 右上角：总用量（811.0 KB / 1 个文件）+ 删除 Bucket⚡。

## 登录页（login.jpg）

- 访问 https://IP:9527，默认自签证书（浏览器提示不安全）。
- 两种登录：用户名密码（client_config 里的 username/password）、
  Telegram 验证码（点发送验证码，机器人发码，60 秒内输入）。
- 密码输错太多会锁定最长 30 分钟，可改用 Telegram 验证码或重启客户端解除。

## 克隆时要做的取舍

- **做**：三栏布局、主机卡片、终端（xterm.js + WebSocket）、创建实例四卡表单、
  快捷开机、Profile 切换、资源监控、SFTP、批量命令、主题切换（先做 2-3 个主题）。
- **不做**：⚡ 付费功能、在线客服、8 种主题全做（先做经典 + 星夜两个）、
  动画插画背景（可用纯色/渐变代替）。
- **技术栈**：FastAPI + WebSocket + Paramiko（后端）+ xterm.js（前端），
  参考 py-web-ssh，不要用 tornado。
